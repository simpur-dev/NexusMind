# 世界模型闭环流程图

```
                         ┌─────────────────────────┐
                         │     OASIS 多Agent模拟     │
                         │   (run_parallel_sim.py)   │
                         │                           │
                         │  每个Agent基于人设+记忆    │
                         │  执行: 发帖/评论/转发/...  │
                         └─────────┬─────────────────┘
                                   │
                          ① 本轮行动数据 (IPC)
                                   │
                                   ▼
┌──────────────────────────────────────────────────────────┐
│                  WorldStateEngine (主进程)                 │
│                                                          │
│  ② LLM分析行动 → 识别事件                                │
│     例: "大量负面评论涌现" → 信任危机事件 (severity=0.7)  │
│                                                          │
│  ③ 更新六维状态变量                                       │
│     ┌────────────────────────────────────────┐           │
│     │  关注度  0.65  ↑   恐慌度  0.42  ↑     │           │
│     │  信任度  0.20  ↓   极化度  0.55  ↑     │           │
│     │  风险    0.28  ↑   稳定性  0.48  ↓     │           │
│     └────────────────────────────────────────┘           │
│                                                          │
│  ④ CausalGraphEngine 推断因果关系                         │
│     事件A ──触发──▶ 事件B ──加剧──▶ 事件C                │
│                                                          │
└──────────────────────────┬───────────────────────────────┘
                           │
                  ⑤ 写回 world_state.json
                    (偏差>0.15时才注入)
                           │
                           ▼
                ┌─────────────────────┐
                │  世界状态注入Agent   │
                │  环境感知提示词      │
                │  (中性观察语言)      │
                └──────────┬──────────┘
                           │
                  ⑥ 下一轮模拟开始
                           │
                           ▼
                         ┌───┐
                         │ ① │ ← 回到起点，新一轮循环
                         └───┘
```

## 一句话总结

```
Agent行动 → 事件检测 → 状态更新 → 因果推断 → 注入环境 → 影响下轮行动
    ①           ②          ③          ④         ⑤            ⑥
```

## 产出物

| 文件 | 内容 |
|------|------|
| `actions.jsonl` | 每轮全部Agent行为 |
| `events.jsonl` | 系统识别的事件 |
| `world_state_history.jsonl` | 每轮六维状态快照 |
| `causal_edges.jsonl` | 事件间因果关系 |
