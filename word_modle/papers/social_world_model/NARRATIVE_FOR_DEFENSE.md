## 一、30 秒电梯演讲

> **NexusMind 的核心，不是“让很多 Agent 发帖”，而是“把一份现实材料变成一个可持续演化、可注入变量、可比较轨迹的数字平行社会”。**
> 评委只需上传任意一份舆情简报、政策草案或分析报告，系统会自动：（1）用知识图谱还原现实锚点；
> （2）生成一群有立场、有偏好、有长期记忆线索的 LLM Agent；（3）让他们在一个带**世界状态反馈闭环**的虚拟社交平台里自主演化；
> （4）输出一份由 Agent 行为、世界状态轨迹和因果链共同支撑的可解释推演报告。
>
> **世界模型带来的质变**是：系统从“多 Agent 内容模拟器”升级为“可观测、可干预、可比较的社会推演引擎”。
> 它第一次能回答的，不只是“谁说了什么”，而是“局势为什么升温、什么时候转折、改一个条件后会不会变”。
> 我们已经把 **“世界状态 → Agent 感知 → Agent 行动 → 新世界状态”** 这个闭环真正跑通，并在大规模 LLM 盲评中以 **70% 胜率**验证了它的效果。

## 二、“加入世界模型之前”的项目长什么样

先说明一点：NexusMind 最初对外承诺的是 **Predict Anything / Parallel Digital World / God’s-eye Variable Injection / Decision Rehearsal Lab**。

在 v7 之前，NexusMind 的骨架已经是：

```
  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
  │ 文档上传 │ -> │ 图谱构建 │ -> │Profile 生成│ -> │ OASIS 模拟│ -> 报告
  └──────────┘    └──────────┘    └──────────┘    └──────────┘
```

这条链路已经能运行：GraphRAG 抽取实体/关系、LLM 自动出 Agent 人设、OASIS 搭好 Reddit/Twitter 风格的平台、几百个 LLM Agent 在里面发帖回帖。

**但更准确地说，那个阶段的系统仍然更像：**

- **GraphRAG + persona-driven 多 Agent 模拟 + ReportAgent 总结**

它能生成很像真的互动，但还不足以完全支撑“高保真数字世界”“变量注入”“未来轨迹推演”这些更高的承诺。

**原因在于，它有四个被论文明确指出的硬伤：**

| 硬伤 | 论文证据 | 表现 |
|------|---------|------|
| **Agent 无法感知环境** | Mou et al. (ACM CSUR 2026) §4.1.1："environment states record instant information from the environment during the scenario. They directly influence the agents' decision-making and behavior." | Agent 只看得到自己的 timeline，**看不到“讨论整体走向”**，像瞎子摸象 |
| **没有显式的社会局势与轨迹** | *World Models Survey*：world model 的核心是理解外部 dynamics 并计算 next state | 每一轮都像在续写帖子，**但系统自己并不知道现在是“升温”“失控”还是“缓和”** |
| **干预只停留在内容层** | OASIS / SocioVerse 都强调环境状态会反过来影响行为 | “发一个官方声明”本质上只是多了一条帖子，**还不是对局势变量的系统性干预** |
| **难解释群体涌现** | Mou et al. §8.3 Challenge 3："the black-box nature of LLMs makes it hard to provide rigorous causal explanations for individual behaviors or collective outcomes." | 报告能总结“大家情绪很激动”，但**说不清为什么会激动、怎么就缓和了** |

**简言之：之前的系统更像“很多角色在互动”，还不像“一个社会局势在演化”。**

> 这也是为什么：如果没有世界模型，README 里那句“高保真数字世界”“上帝视角注入变量”“预演未来走向”其实是不够站得稳的。

## 三、世界模型到底加了什么

我们现在做成的，不是凭空自造一个概念，而是对 **SocioVerse、OASIS、POSIM、Generative Agents、World Models Survey** 等论文共同思想的工程化整合。

### 3.1 v7 已经做成的闭环（第一阶段质变）

```
                    ┌──────────────────────────────────┐
                    │   WorldStateEngine (6-dim state) │
                    │  attention / panic / trust /     │
                    │  polarization / risk / stability │
                    └──────────────┬───────────────────┘
                                   │ 写入共享状态
    ┌──────────────────┐   state + events   ┌──────────────────┐
    │  LLM Agents      │ ←─────注入 prompt──│  Prompt Builder  │
    │  (OASIS Agents)  │                    │  RC 客观观察句    │
    └──────────┬───────┘                    └──────────────────┘
               │ 新行为
               ▼
    ┌──────────────────┐   因果推断   ┌──────────────────┐
    │ CausalGraphEngine│ ←──────────  │  事件流          │
    │ trig/amp/sup/cor │              │                  │
    └──────────────────┘              └──────────────────┘
```

1. **世界状态引擎**：每轮根据动作更新 6 维社会状态向量，并检测关键事件
2. **Prompt 注入层（v7 核心）**：通过 `read_world_state()` → `build_world_state_prompt()` → `patch_oasis_environment()` 把状态/趋势/事件压缩成 Agent 可读的**客观观察句**，写回 OASIS 环境 prompt
3. **因果图谱引擎**：自动识别 `triggered / amplified / suppressed / correlated` 等事件关系，支持报告和前端回溯
4. **Profile 认知字段扩展**：Agent Profile 已增加 `internal_goals / utility_weights / initial_stance / emotional_tendency / susceptibility` 等字段，为后续更深的人设入模打基础

### 3.2 这不是“小优化”，而是四个层面的质变

| 质变 | 没有世界模型时 | 加了世界模型之后 |
|------|---------------|------------------|
| **从角色互动到局势演化** | 系统知道“谁发了什么” | 系统开始显式表达“热度上升、信任下降、风险变化”等**局势状态** |
| **从开放环生成到闭环推演** | 动作被记录，但不会系统性反馈到下一轮 | 动作先更新世界状态，世界状态再反馈给 Agent，形成**路径依赖** |
| **从内容干预到状态干预** | “官方回应”只是多一条帖子 | 干预会体现在世界状态和后续轨迹上，开始具备**策略试演**意义 |
| **从事后总结到可解释推演** | 报告偏“总结大家说了什么” | 报告可以基于状态曲线、关键事件、因果链回答“为什么会这样发展” |

**一句话说：世界模型让 NexusMind 从“多 Agent 演戏”升级为“社会局势推演”。**

### 3.3 也要诚实说清楚：我们已经做到哪一步、下一步做什么

当前已经完成的是：

- **[已完成]** 宏观世界状态反馈闭环
- **[已完成]** 事件检测与因果关系回溯
- **[已完成]** 基于客观观察句的 Agent 环境感知增强
- **[已完成]** 人设中的认知字段扩展

下一阶段正在推进的是：

- **[下一步]** 把 persona 进一步编译为 `AgentPrior`
- **[下一步]** 显式维护 `belief / emotion / trust / attention` 级别的 `AgentCognitiveState`
- **[下一步]** 让同一世界状态对不同 agent 产生更强的个性化感知

这意味着：**我们已经完成第一阶段的质变——从多 Agent 模拟器变成宏观闭环推演器；下一阶段要完成的是“让 agent 的内部认知真正进入 world model 内核”。**

## 四、关键技术陷阱：Empathy Paradox（有话可讲的故事）

这是本项目最精彩的**"踩坑–爬起"故事**，非常适合答辩时讲。

### 故事

我们一开始 v6 的世界模型，为了让 Agent "更敏感地响应危机"，引入了一批"情绪放大型"观察句，比如：

> "紧张情绪还在进一步扩散" / "气氛骤然绷紧" / "恐慌感显著缓解"

效果是：**Win Rate 从 v5 的 61% 反而跌到了 56%，稳定性从 58% 崩到 33%。**

### 转折

回头精读 POSIM 2025 论文 §6，发现一个叫 **Empathy Paradox** 的反直觉结论（Table 7）：

| 干预策略 | 100% 覆盖下的 NER（越低越好）|
|----------|-----------------------------|
| 对照组 | 0.844 |
| **共情引导 (Empathy Priming)** | **0.878 ↑**（反而更糟）|
| **理性认知 (Rational Cognition)** | **0.571** ↓ |
| 情绪调节 (Emotional Regulation) | 0.572 ↓ |

> 论文原文：*empathetic guidance intended to ease group antagonism instead amplifies negative sentiment in complex multi-agent interactions*.

**也就是说：告诉 Agent "大家都很恐慌"，会让 Agent 自己变得更恐慌，负面情绪会像病毒一样反向放大。**

### 修复

v7 据此全面重写 prompt：删除所有"共情代言"措辞，改为**理性认知式的客观观察**：

| v6（共情代言，错）| v7（理性观察，对）|
|-------------------|-------------------|
| 紧张情绪还在进一步扩散 | 近几轮新信息进入的节奏加快 |
| 恐慌感显著缓解 | 讨论中关于下一步执行的具体问题占比上升 |
| 气氛骤然绷紧 | 围绕同一事实目前存在差异较大的多种解读 |

结果：**Win Rate 从 56% 升至 70%，稳定性从 33% 升至 83%。**

**这个故事本身就是一个极有说服力的"论文指导工程"案例。**

## 五、用数据说话：70% 胜率的盲评

### 实验设计

- **3 个场景** × **10 个 Agent** × **12 轮模拟** × **2 个随机种子** × **3 个 LLM 裁判盲评** = 6 次 A/B × 18 次裁决
- A 组：原始 OASIS（无世界模型）
- B 组：加上世界模型
- 指标：5 个定量（情感均值/多样性/危机敏感/恢复响应/稳定性）+ 4 个定性（情感演化/角色差异/危机响应/自然度）

### 结果（v7）

| 维度 | 结果 |
|------|------|
| **总胜率** | **70 %** ✅ |
| Judge 单票 | B:12 / A:6（67% B）|
| Judge 多数决 | B:3 / A:3 |
| Naturalness 均分 | B=78 vs A=64（**+14**）|
| Crisis Response 均分 | B=87 vs A=68（**+19**）|
| Emotion Evolution 均分 | B=84 vs A=72（**+12**）|

> 这个结果不等于“我们已经能 100% 预测现实”，而是说明：**引入世界状态反馈后，模拟轨迹更稳定、更自然、更接近真实社会反应模式。** 这恰恰是“数字平行社会”比“多 Agent 内容生成”更进一步的证据。

### Judge 原话摘录（可直接念）

> "组 Y 的情感演化更真实（从焦虑 → 质疑 → 部分信任 → 持续监督），角色差异化同样出色但更克制自然……
> 整体更贴近真实社交媒体生态的呼吸感与颗粒度。"

## 七、可能被问的问题（FAQ）

**Q1：这个世界模型是你们自己发明的吗？**
A：不是。我们不是“拍脑袋造了一个世界模型”，而是综合吸收了 **SocioVerse、OASIS、POSIM、Generative Agents、World Models Survey** 等论文的共同思想，再把它们工程化落到可运行代码里。我们的创新点主要有三条：（1）把论文里的 world-state feedback 真正做成工程闭环；（2）发现并规避了 POSIM 自己指出的"共情悖论"陷阱；（3）做了一套严格的 LLM 盲评验证框架。

**Q2：70% 的胜率怎么保证不是碰运气？**
A：6 次独立运行（3 场景 × 2 种子），每次 3 个裁判，共 18 次裁决；结果 JSON 在 `llm_validation_large_result.json` 可复现；相关 world model 改动有 **48 项单元测试**回归保护。

**Q3：为什么不直接用 OASIS？**
A：OASIS 解决的是“社交平台骨架”，但它本身不等于“数字世界推演引擎”。没有 world model 时，Agent 更像信息孤岛，只能局部互动；有了 world model 以后，系统才开始有共享局势、阶段变化、干预反馈和因果回溯。也就是说：**OASIS 提供平台，world model 让平台变成推演系统。**

**Q4：你们和 Stanford 的 Generative Agents 有什么区别？**
A：Stanford 的 25 小镇是“微观生活模拟”，重点是 agent 的日常生活与记忆；我们的定位是“社会局势推演”，重点是**宏观状态、事件因果、干预反馈和报告解释**。两者都重要，但目标不同：前者更像行为仿真，后者更像决策预演。

**Q5：这个系统有什么实际应用价值？**
A：（1）舆情预测演练——政府/高校/企业在危机发生前跑沙盘；（2）策略 A/B 测试——比较"官方回应 vs 不回应"、"早回应 vs 晚回应"的轨迹差异；（3）品牌/营销仿真——测试不同内容策略的传播结果；（4）学术研究——在伦理友好的数字社会里研究信息传播和群体行为。

**Q6：相比已有的舆情分析工具（Python 爬虫 + 情感分析）强在哪里？**
A：传统工具是“事后统计”，我们是“事前推演”。传统工具可以告诉你“昨天大家情绪如何”，但无法系统回答“如果今晚官方发了道歉声明，明天情绪会怎样演化”；我们能回答，是因为 Agent 不只是生成文本，而是处在一个有世界状态反馈闭环的虚拟环境中。

**Q7：你们现在的世界模型已经完整了吗？**
A：我们会很诚实地说：**已经完成第一阶段的核心闭环，但还不是终点。** 现在已经做成的是宏观世界状态、状态反馈、事件检测、因果回溯；下一阶段会把 persona 更深地编译成认知先验，并显式建模 `belief / emotion / trust / attention`。这不是缺陷，而是清晰的演进路线：先做“局势闭环”，再做“认知入模”。
