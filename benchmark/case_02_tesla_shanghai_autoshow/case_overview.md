# 案例二：特斯拉上海车展维权事件

## 基本信息

| 项目 | 内容 |
|------|------|
| **案例类型** | 企业危机公关 / 消费者维权 / 官方监管介入 |
| **核心议题** | 车主车展维权引发舆论风暴，企业回应方式导致二次升级 |
| **核心主体** | 特斯拉、维权车主、媒体、网民、市场监管部门 |
| **推荐作为** | 主 benchmark 案例 2 |
| **验证指标** | TCS、TPH、EOA，以及 A/B 策略敏感性 |

## 事件简述

2021 年上海车展期间，特斯拉车主因刹车问题在展台维权，视频迅速传播引发舆论风暴。特斯拉初期回应强硬（"绝不妥协"），导致舆情二次升级。随后市场监管部门介入，企业态度转变，事件逐步收敛。

## 阶段划分

| 阶段 | 阶段名称 | 主要特征 | 情绪趋势 |
|------|---------|---------|---------|
| **P1** | 爆发期 | 维权视频传播，引发大量关注 | 负面快速上升 |
| **P2** | 企业强硬回应期 | 特斯拉发声"绝不妥协"，舆论愤怒升级 | 负面急剧攀升 |
| **P3** | 监管介入期 | 市场监管部门要求配合调查，媒体密集报道 | 负面持续高位，出现分化 |
| **P4** | 企业态度转变期 | 特斯拉致歉、配合调查，舆论出现缓和迹象 | 混合情绪，部分转正 |
| **P5** | 收敛期 | 后续处理推进，热度逐步下降 | 回落趋于中性 |

## 关键转折点（Top-3）

1. **T1 — 维权视频爆发**：车主在车展站上车顶维权，视频迅速传播
2. **T2 — 企业强硬回应**：特斯拉高管表态"绝不妥协"，引发二次舆论高峰
3. **T3 — 监管部门介入**：市场监管总局要求特斯拉配合调查，企业态度转变

## 关键主体

| 主体 | 类型 | 角色 | 重要性 |
|------|------|------|--------|
| 特斯拉 | organization | 被投诉企业，危机公关主体 | 高 |
| 维权车主 | individual | 事件触发者，消费者维权代表 | 高 |
| 主流媒体 | media | 报道扩散，舆论监督 | 高 |
| 普通网民 | group | 情绪放大，话题传播 | 中 |
| 市场监管部门 | regulator | 权威介入，改变事件走向 | 高 |

## 建议 A/B 对比变量

- **A 组**：企业在初期即表态配合调查、致歉
- **B 组**：企业初期强硬回应（真实路径）
