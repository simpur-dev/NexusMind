# 案例二：华中农业大学研究生实名举报导师学术不端事件

## 基本信息

| 项目 | 内容 |
|------|------|
| **案例类型** | 高校舆情 / 学术伦理治理 / 导师与研究生关系 |
| **核心议题** | 研究生实名举报导师学术不端与管理失范，舆论焦点从个案迅速上升为高校科研治理问题 |
| **数据来源** | 华中农业大学官方通报（2024-01-19、2024-02-06） |
| **核心主体** | 校方、举报研究生、涉事导师、媒体、学界、教育主管部门 |
| **推荐作为** | 主 benchmark 案例 2 |
| **验证指标** | TCS、TPH、KAC、EOA（全部 4 项） |

## 事件简述

2024 年 1 月，华中农业大学 11 名研究生公开实名举报导师涉嫌学术不端、压榨学生与科研管理失范。举报材料引发社会高度关注，学校随后成立调查组并发布通报，初步认定举报反映的实验图片、数据、结果等问题基本属实。后续学校公布进一步处理结果，对涉事导师作出撤销校内职务、解除聘用关系、申请撤销教师资格等处理，并为在读研究生重新安排培养方案。舆论讨论由个案迅速扩展至高校科研伦理、导师权力边界与研究生保护机制。

## 阶段划分

| 阶段 | 阶段名称 | 主要特征 | 情绪趋势 |
|------|---------|---------|---------|
| **P1** | 曝光期 | 11 名研究生实名举报材料公开，科研造假与导师压迫问题引发关注 | 负面快速上升 |
| **P2** | 调查启动期 | 学校成立调查组并暂停涉事导师相关工作，公众等待权威结论 | 负面达到峰值 |
| **P3** | 深挖扩散期 | 媒体与学界持续追问学术伦理、导师权力与学生处境 | 负面高位持续 |
| **P4** | 处理通报期 | 学校公布最终处理结果，舆论对处置力度与制度修复展开评价 | 混合情绪，部分转正 |
| **P5** | 反思收敛期 | 热度回落，讨论转向科研生态和研究生培养制度完善 | 回落趋于中性 |

## 关键转折点（Top-3）

1. **T1 — 实名举报公开**：研究生发布长篇实名举报材料，事件迅速出圈
2. **T2 — 初步认定属实**：学校通报称举报涉及的实验图片、数据、结果等问题基本属实
3. **T3 — 最终处理公布**：学校解除聘用、申请撤销教师资格，并调整研究生培养安排

## 关键主体

| 主体 | 类型 | 角色 | 重要性 |
|------|------|------|--------|
| 华中农业大学（校方） | organization | 调查处置主体，负责发布通报与落实后续处理 | 高 |
| 举报研究生 | group | 事件触发者，以实名方式提升信息可信度 | 高 |
| 涉事导师 | individual | 被举报对象，直接决定事件冲突强度 | 高 |
| 媒体 / 自媒体 | media | 报道扩散并推动话题升级到科研治理层面 | 高 |
| 学界 / 科研共同体 | group | 将个案延展为对学术伦理与制度的讨论 | 中 |
| 教育主管部门 | regulator | 作为更高层级治理与规范参照对象 | 中 |

## 建议 A/B 对比变量

- **A 组**：学校在首日即发布透明说明，并同步给出学生保护与培养安置方案
- **B 组**：学校先简短回应、等待调查完成后再公布完整处理结果

## 展示注意事项

- 重点展示“实名举报 + 校方响应 + 制度问责”三者之间的因果链
- 强调系统对高校科研治理类舆情的可解释推演能力
- 避免把重点放在个体道德猎奇，聚焦制度与治理逻辑
