# 案例一：武汉大学肖某瑫与杨某媛纠纷事件

## 基本信息

| 项目 | 内容 |
|------|------|
| **案例类型** | 高校舆情 / 学生纠纷处置 / 程序正义与学术诚信争议 |
| **核心议题** | 肖某瑫与杨某媛矛盾纠纷引发社会关注，涉及纪律处分撤销、学位论文复核、多人问责 |
| **数据来源** | 武汉大学官方通报（2025-09-20） |
| **核心主体** | 校方、肖某瑫、杨某媛及导师、校友、媒体、网民、司法机关 |
| **推荐作为** | 主 benchmark 案例 1 |
| **验证指标** | TCS、TPH、KAC、EOA（全部 4 项） |

## 事件简述

肖某瑫与杨某媛的矛盾纠纷引发社会关注。武汉大学组建调查复核专家组，对肖某瑫纪律处分、杨某媛学位论文等进行全面调查复核。法院二审判决维持一审（驳回杨某媛全部诉讼请求），校方撤销肖某瑫记过处分，维持杨某媛硕士学位但指出论文存在百余处不规范，并对多名责任人进行问责处分。舆论焦点从个案逐步升维为对高校治理能力、学术诚信审查和程序透明度的质疑。事件中还伴随大量不实信息传播。

## 阶段划分

| 阶段 | 阶段名称 | 主要特征 | 情绪趋势 |
|------|---------|---------|---------|
| **P1** | 爆发期 | 肖某瑫与杨某媛纠纷曝光，肖某瑫被记过处分引发关注 | 负面快速上升 |
| **P2** | 扩散期 | 媒体介入报道，大量不实信息传播，网民大量涌入 | 负面达到峰值 |
| **P3** | 回应期 | 法院二审驳回杨某媛诉讼；校方撤销处分、公布论文复核与问责 | 混合情绪，部分转正 |
| **P4** | 二次传播期 | 质疑论文不规范仍维持学位、问责力度不足，升维到制度层面 | 负面二次上升 |
| **P5** | 收敛期 | 热度下降，关注校方后续整改与问责落实 | 回落趋于中性 |

## 关键转折点（Top-3）

1. **T1 — 事件曝光**：肖某瑫与杨某媛纠纷曝光，肖某瑫被记过处分引发社会关注
2. **T2 — 校方通报**：法院判决驳回杨某媛诉讼，校方撤销处分、公布论文复核结果与问责处分
3. **T3 — 程序正义质疑**：公众质疑论文百余处不规范仍维持学位、导师仅暂停招生两年处罚过轻，引发二次争议

| 主体 | 类型 | 角色 | 重要性 |

## 建议 A/B 对比变量

- **A 组**：校方在爆发期就公布调查复核进展、司法程序状态和论文审查详情
- **B 组**：校方在调查复核完成后才一次性发布完整通报（真实路径）
