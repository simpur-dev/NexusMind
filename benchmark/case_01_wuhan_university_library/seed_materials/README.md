# 武汉大学图书馆争议事件 — 种子材料

## 材料采集清单

运行 benchmark 前，请在本目录下放入以下材料文件：

### 必选材料（至少准备 2 项）

- [ ] **校方通报 / 官方声明**
  - 如：校方关于撤销处分的公告原文
  - 建议保存为 `01_official_statement.txt`

- [ ] **时间线新闻报道**
  - 如：主流媒体对事件经过的综合报道
  - 建议保存为 `02_news_timeline.txt`

### 推荐材料（提升图谱质量）

- [ ] **舆情分析文章**
  - 如：自媒体或研究机构对该事件的舆情分析
  - 建议保存为 `03_opinion_analysis.txt`

- [ ] **社交媒体评论摘要**
  - 如：微博/知乎等平台的代表性评论汇编
  - 建议保存为 `04_social_comments.txt`

## 材料格式要求

- 使用纯文本（`.txt`）或 Markdown（`.md`）格式
- 编码统一为 UTF-8
- 弱化具体个人姓名，用"某学生""当事人"等替代
- 每个文件开头注明来源和日期

## 材料用途

这些材料将作为 NexusMind 的输入种子：
1. 上传至系统（文件上传模式）
2. 系统自动进行本体生成 → 图谱构建 → Agent 世界 → 仿真推演
3. 推演结果与 `reference_data.json` 中的参考真值做对照评分
