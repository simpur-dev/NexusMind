# 案例三：李佳琦 / 花西子眉笔事件

## 基本信息

| 项目 | 内容 |
|------|------|
| **案例类型** | KOL 信任危机 / 消费者情绪 / 品牌公关 |
| **核心议题** | 头部主播不当言论引发信任崩塌与品牌连带危机 |
| **核心主体** | 李佳琦、花西子、消费者、竞品品牌、媒体 |
| **推荐作为** | 补充 benchmark 案例 3 |
| **验证指标** | TCS、TPH、KAC |

## 事件简述

2023 年 9 月，头部主播李佳琦在直播中因消费者质疑花西子眉笔价格，发表"哪里贵了""有没有认真工作"等言论，引发大范围消费者愤怒。事件导致品牌方花西子遭受连带冲击，竞品借势营销（如蜂花等国货品牌），形成多层次舆情链路。

## 阶段划分

| 阶段 | 阶段名称 | 主要特征 | 情绪趋势 |
|------|---------|---------|---------|
| **P1** | 爆发期 | 直播片段传播，消费者愤怒 | 负面爆发式上升 |
| **P2** | 信任崩塌期 | 大规模取关、退货，信任急剧下降 | 负面达到峰值 |
| **P3** | 品牌连带期 | 花西子被波及，竞品借势营销 | 负面分化，竞品正面 |
| **P4** | 延迟回应期 | 李佳琦道歉，但被认为不够真诚 | 混合情绪，恢复缓慢 |
| **P5** | 长尾期 | 持续低热度讨论，信任修复漫长 | 缓慢趋于中性 |

## 关键转折点（Top-3）

1. **T1 — 不当言论传播**：直播片段在社交媒体病毒式传播
2. **T2 — 信任崩塌**：大规模取关、退货潮
3. **T3 — 延迟道歉**：李佳琦道歉视频发布，但被质疑诚意

## 建议 A/B 对比变量

- **A 组**：主播在事件后 2 小时内真诚道歉
- **B 组**：主播延迟多天道歉（真实路径）
